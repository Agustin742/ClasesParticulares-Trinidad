Repaso — let y const03 / 51

Las dos formas de declarar. La diferencia es una sola.

let contador: number = 0;
contador = 1;              // ✔ let se puede reasignar

const MAXIMO: number = 3;
MAXIMO = 5;                // ✘ const no se reasigna
¿Se reasigna?Cuándo la usás
letSíEl valor va a cambiar: un contador, un acumulador, un estado
constNoEl valor no cambia nunca: una constante, un objeto que creás una vez
La regla práctica

Empezá siempre con const. Cambiá a let sólo cuando el compilador te obligue.

¿Por qué al revés y no “let por las dudas”? Porque una const te da una garantía: leyendo esa línea ya sabés que ese nombre va a significar lo mismo en todo el bloque. Con let tenés que revisar todo el archivo para estar segura.

Ojo con una que ya te crucé

const sirve para variables adentro de una función o un bloque. Para una propiedad de clase que no cambia, la palabra es readonly:

class Socio {
  private readonly MAXIMO: number = 3;   // ← en una clase va readonly
}

Son la misma idea —“esto no se reasigna”— en dos lugares distintos.

Ver respuestaClick · o tecla R

Imprime cinco líneas: 8, 6, 10, 4 y undefined.

El error está en el <=: tiene que ser <. length es 4 y los índices válidos son 0, 1, 2 y 3. Con <=, la última vuelta usa i = 4, que no existe.

Y no se rompe porque pedir un índice inexistente devuelve undefined en vez de tirar error. El programa sigue como si nada.

Eso lo hace peligroso, no inofensivo. Si en vez de imprimir estuvieras sumando, 8+6+10+4+undefined da NaN — y ese NaN se propaga hasta que alguien, tres pantallas después, se pregunta por qué el total dice “NaN”.

Se llama error de uno (off-by-one), y se evita casi siempre de la misma forma: no escribiendo el for a mano.

notas.forEach(nota => console.log(nota));

No podés equivocarte en algo que no escribís.

Métodos — agregar y sacar09 / 51

Los cuatro que vas a usar todos los días. Los cuatro modifican el array original.

const cola: string[] = ["Ana", "Juan"];

cola.push("Pedro");      // al FINAL      → ["Ana","Juan","Pedro"]
cola.pop();              // saca el ÚLTIMO → devuelve "Pedro"
cola.unshift("Lucía");   // al PRINCIPIO  → ["Lucía","Ana","Juan"]
cola.shift();            // saca el PRIMERO→ devuelve "Lucía"
MétodoDónde operaQué devuelve
push(x)FinalLa nueva longitud
pop()FinalEl elemento que sacó
unshift(x)PrincipioLa nueva longitud
shift()PrincipioEl elemento que sacó
El que saca del medio

Es el que te va a hacer falta para devolverLibro().

const i = libros.indexOf(libro);   // −1 si no está
if (i !== -1) {
  libros.splice(i, 1);            // desde i, borrá 1
}

Fijate el if.

indexOf devuelve -1 cuando no encuentra el elemento — no undefined, no null. Y splice(-1, 1) borra el último elemento, que no es para nada lo que querías.

Sin ese if, pedirle a un socio que devuelva un libro que no tiene le borra otro libro cualquiera.

Un bug perfecto: silencioso, con datos plausibles, imposible de encontrar leyendo.

Métodos — recorrer y buscar10 / 51
Recorrer

forEach ejecuta algo por cada elemento. Es el reemplazo del for a mano.

animales.forEach(animal => animal.hacerSonido());
//               ↑ el parámetro es cada elemento, uno por vez
Buscar — cuatro preguntas distintas
const notas: number[] = [8, 6, 10, 4];

notas.includes(10);        // ¿está el 10?            → true
notas.indexOf(10);         // ¿en qué posición?       → 2
notas.find(n => n >= 9);   // el PRIMERO que cumpla   → 10
notas.some(n => n < 6);    // ¿hay ALGUNO?            → true
notas.every(n => n >= 4);  // ¿cumplen TODOS?         → true
MétodoLa pregunta que contestaDevuelve
includes(x)¿Está este valor exacto?boolean
indexOf(x)¿En qué posición está?Número, o −1
find(fn)¿Cuál es el primero que cumple?El elemento, o undefined
some(fn)¿Hay al menos uno?boolean
every(fn)¿Cumplen todos?boolean

includes vs some

includes compara con === un valor exacto. some evalúa una condición.

Si buscás un objeto por alguna de sus propiedades, va some o find, nunca includes.

Métodos — transformar11 / 51

Estos no modifican el original: devuelven un array nuevo.

const precios: number[] = [100, 250, 80, 500];

const conIva = precios.map(p => p * 1.21);
// [121, 302.5, 96.8, 605]   ← array NUEVO, mismo largo

const caros = precios.filter(p => p > 200);
// [250, 500]                ← array NUEVO, más corto

const total = precios.reduce((acum, p) => acum + p, 0);
// 930                       ← NO es un array: un solo valor
MétodoQué haceLargo del resultado
mapTransforma cada elementoIgual al original
filterSelecciona los que cumplenMenor o igual
reduceAcumula todo en un valorUn valor, no un array
reduce merece un párrafo

Es el que más cuesta, y lo vas a usar hoy en el integrador.

precios.reduce((acumulado, precio) => acumulado + precio, 0);
//              ↑ lo que llevo  ↑ el actual              ↑ desde dónde

Lleva una bolsa (acumulado) que arranca en 0, y por cada elemento decide qué meter en la bolsa. Al final, devuelve la bolsa.

Es exactamente esto, escrito en una línea:

let acumulado = 0;
precios.forEach(precio => { acumulado = acumulado + precio; });

interface Cerrable { cerrarCaja(): void; }

abstract class Empleado {
  constructor(protected nombre: string,
              protected sueldoBase: number) {}
  mostrarDatos(): void {
    console.log(`${this.nombre} — $${this.calcularSueldo()}`);
  }
  abstract calcularSueldo(): number;
}

class Mozo extends Empleado implements Cerrable {
  constructor(n: string, s: number, private propinas: number) {
    super(n, s);
  }
  calcularSueldo(): number { return this.sueldoBase + this.propinas; }
  cerrarCaja(): void { console.log(`${this.nombre} cerró la caja`); }
}

class Cocinero extends Empleado {
  constructor(n: string, s: number, private antiguedad: number) {
    super(n, s);
  }
  calcularSueldo(): number { return this.sueldoBase + this.antiguedad * 5000; }
}

class Producto {
  constructor(private nombre: string, private precio: number) {}
  getPrecio(): number { return this.precio; }
}

class Mesa { constructor(private numero: number) {} }
class ItemPedido {
  constructor(private producto: Producto,
              private cantidad: number) {}

  subtotal(): number {
    return this.producto.getPrecio() * this.cantidad;
  }
}

class Pedido {
  private items: ItemPedido[] = [];      // ◆ COMPOSICIÓN

  constructor(
    private mesa: Mesa,                 // ◇ ya existía
    private mozo: Mozo                  // ◇ ya existía
  ) {}

  agregarItem(producto: Producto, cantidad: number): void {
    this.items.push(new ItemPedido(producto, cantidad));
    //              ↑ el new ADENTRO
  }

  calcularTotal(): number {
    return this.items.reduce((t, item) => t + item.subtotal(), 0);
  }

  pagar(medio: MedioDePago): boolean {   // ◇ llega de afuera
    return medio.pagar(this.calcularTotal());
  }
}
